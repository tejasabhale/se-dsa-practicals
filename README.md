# DS Practical Solutions SE

A responsive code library for Second Year Engineering Data Structures practical assignments. Browse C programs, navigate between assignments, and copy code with a single click.

## Features

- **9 Practical Assignments:** Access all nine Data Structures practical programs in one place.
- **One-Click Copying:** Copy individual C programs using the built-in copy button.
- **Quick Navigation:** Jump directly to an assignment using the numbered index.
- **Responsive Layout:** Designed for desktop, tablet, and mobile screens.
- **Readable Code Blocks:** View programs in clean, horizontally scrollable code panels.
- **Simple Interface:** Find and review practical programs without unnecessary clutter.

## Assignments

1. Linear Search and Binary Search
2. Bubble Sort and Selection Sort
3. Hash Table and Collision Resolution Techniques
4. Club Member Management Using a Singly Linked List
5. Cinemax Ticket Booking Using a Doubly Linked List
6. Infix to Postfix Expression Conversion Using a Stack
7. Pizza Parlor Job Queue Using a Queue
8. Binary Search Tree Operations
9. Flight Paths and Graph Connectivity Using DFS

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before proceeding.

### Clone the Repository

```bash
git clone https://github.com/tejasabhale/se-dsa-practicals.git
cd se-dsa-practicals
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the website.

## How to Use

1. Open the website.
2. Select an assignment number from the index to jump to its code.
3. Read the program in the code panel.
4. Click **Copy Code** to copy the selected program.
5. Review and understand the logic before using the program in your practical work.
